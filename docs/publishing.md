# Publishing to npm

Nothing is published from ch-packs. Each package of the family is published as `@countinghouse/<name>` from its own repository under [mchen6](https://github.com/mchen6), as soon as it is ready (spec, "One repository per package"), by that repository's `.github/workflows/publish.yml` under npm trusted publishing; its README's "Publishing" section says how: [ch-local](https://github.com/mchen6/ch-local#publishing), [ch-access-github](https://github.com/mchen6/ch-access-github#publishing), [ch-pack-ci-failure-triage](https://github.com/mchen6/ch-pack-ci-failure-triage#publishing), [ch-report](https://github.com/mchen6/ch-report#publishing), and each `ch-step-*` repository alike.
